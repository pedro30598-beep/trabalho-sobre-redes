O que é uma rede de computadores?

É a conexão entre dispositivos para compartilhar informações e recursos. A seguir, você vai conhecer os principais conceitos, equipamentos e tecnologias de rede.

01

PARTE 1

Fundamentos e organização de redes

O que é uma rede de computadores?

É a ligação entre dois ou mais dispositivos para trocar informações e compartilhar recursos, como arquivos, impressoras e acesso à internet.

Exemplo do dia a dia: em uma casa, celular, televisão e computador podem se conectar ao mesmo roteador. Assim, todos conseguem acessar a internet pela mesma rede.

Infraestrutura de rede

É o conjunto de equipamentos, cabos, conectores e espaços que permite a comunicação. Uma escola, por exemplo, pode ter um roteador, switches, pontos de acesso Wi-Fi, cabos e um local onde os equipamentos ficam organizados.

Cabeamento estruturado

É a organização planejada dos cabos, tomadas e pontos de conexão de um prédio. Essa organização facilita encontrar problemas, fazer mudanças e ampliar a rede. Um cabo muito usado em redes locais é o par trançado, normalmente terminado com conector RJ-45.

Cabo de rede de par trançado

Topologias de rede

Topologia é a forma como os dispositivos estão conectados. A topologia física mostra a ligação dos equipamentos; a lógica mostra como os dados circulam.

Estrela

Todos se ligam a um equipamento central, como um switch.

Barramento

Os dispositivos compartilham um cabo principal.

Anel

Os dispositivos formam um caminho fechado.

Protocolos e comunicação

O que são protocolos?

São regras que organizam a comunicação entre dispositivos. É como combinar um idioma e regras para que todos consigam se entender.

Modelo TCP/IP

É um conjunto de protocolos usado na comunicação pela internet. Ele organiza o envio dos dados desde o aplicativo até a rede física.

AplicaçãoHTTP, HTTPS, DNS
TransporteTCP e UDP
InternetIP
Acesso à redeEthernet e Wi-Fi

DNS, HTTP, HTTPS e portas

  • DNS: localiza o endereço IP relacionado ao nome de um site.
  • HTTP: permite a troca de informações entre navegador e servidor.
  • HTTPS: protege essa comunicação com criptografia.
  • Portas: identificam serviços em um dispositivo. Como exemplos, HTTP costuma usar a porta 80 e HTTPS a porta 443.

PARTE 3

Endereçamento e identificação

Endereço IP

É um endereço usado para identificar um dispositivo em uma rede e permitir que os dados cheguem ao destino correto.

TipoComo é escritoExemplo
IPv4Quatro números separados por pontos192.168.0.10
IPv6Grupos de números e letras separados por dois-pontos2001:db8::1

O IPv6 foi criado para oferecer uma quantidade muito maior de endereços disponíveis.

Outros conceitos importantes

  • Máscara de rede: indica qual parte do endereço IP identifica a rede e qual identifica o dispositivo.
  • Gateway: é a saída para outras redes. Em uma casa, geralmente é o roteador.
  • Endereço MAC: identificador associado à interface de rede do equipamento.
  • Sub-rede: divisão de uma rede maior em redes menores.
Exemplo: um computador pode usar o IP 192.168.0.10 e ter como gateway o roteador 192.168.0.1. Assim, ele sabe para onde enviar dados destinados a outras redes.

PARTE 4

Tecnologias e equipamentos

Tecnologias de conexão

  • Ethernet: tecnologia bastante usada em redes com cabos.
  • Wi-Fi: permite conectar dispositivos sem fio, usando ondas de rádio.
  • Padrões IEEE: normas técnicas que ajudam equipamentos de diferentes fabricantes a funcionar juntos. A família 802.11 está relacionada ao Wi-Fi e a 802.3 à Ethernet.

PARTE 5

Diagnóstico de redes e computação em nuvem

Como investigar problemas de conexão?

O diagnóstico de rede ajuda a descobrir por que um dispositivo não consegue se conectar ou acessar um serviço.

ping

Testa se um destino responde pela rede.

ipconfig

No Windows, mostra informações como IP, máscara e gateway.

tracert

No Windows, mostra etapas do caminho até um destino.

Exemplo: se a internet parece não funcionar, o comando ipconfig ajuda a conferir se o computador recebeu um endereço IP. O ping pode testar a comunicação com outro endereço.

O que é computação em nuvem?

É o uso de recursos de tecnologia pela internet, como armazenamento, programas e servidores. Assim, não é necessário manter toda a estrutura no próprio computador.

ModeloO que ofereceExemplo simples
IaaSInfraestrutura, como máquinas virtuais e armazenamentoAlugar um servidor virtual
PaaSPlataforma para criar e executar programasAmbiente on-line para desenvolver aplicações
SaaSPrograma pronto usado pela internetE-mail ou editor de documentos on-line
